A single original one-line office joke, written to get the biggest laugh out of coworkers.

## Entry

`main.ts` (Node 22, stdlib only, deterministic — no clock, no randomness, no network, no file reads) writes one line to `/output/entry.txt`:

> I told my boss I was burning out, so he handed me a fire extinguisher and moved my deadline to Friday.

## Run

```sh
node main.ts
```

The program guards that the joke is exactly one line of 1–200 characters before writing it.
